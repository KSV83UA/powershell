# Пользователи RDP-сервера

Создание локальных учётных записей на RDP-сервере одним скриптом: по одному пользователю
параметрами, по одному в диалоге, пакетно по списку CSV или серией (`student01`, `student02`, ...).

Запускать на самом сервере в Windows PowerShell 5.1 **от имени администратора**.
Перед созданием по списку проверяйте его ключом `-WhatIf`: он ничего не меняет.

## Файлы

| Файл | Что делает |
|---|---|
| `New-ServerUsers.ps1` | создаёт пользователей: один, диалог или список |
| `New-ServerUsers.cmd` | запуск двойным щелчком (правой кнопкой - «Запуск от имени администратора») |
| `New-ServerUsers.users.example.csv` | пример списка; рабочая копия - `New-ServerUsers.users.csv` |
| `Set-PasswordNeverExpires.ps1` | ставит «Срок действия пароля не ограничен» уже созданным пользователям |

Рабочий список `New-ServerUsers.users.csv` и файлы с паролями `New-ServerUsers.passwords_*.csv`
в git не попадают (`.gitignore`): в них настоящие телефоны и пароли, а репозиторий публичный.

## Способы запуска

### Без параметров

```powershell
.\New-ServerUsers.ps1
```

Скрипт спрашивает, что делать: добавлять по одному с вопросами, всех из
`New-ServerUsers.users.csv` рядом со скриптом или создать серию. Так же работает `New-ServerUsers.cmd`.

### Один пользователь

Достаточно логина:

```powershell
.\New-ServerUsers.ps1 ivanov
```

Или имени и фамилии - логин составится сам, латиницей по шаблону `{f}.{last}`:

```powershell
.\New-ServerUsers.ps1 -FirstName Іван -LastName Петренко
# логин i.petrenko, ФИО «Іван Петренко»
```

Со всеми подробностями:

```powershell
.\New-ServerUsers.ps1 -FirstName Іван -LastName Петренко -Phone '000 000 00 01' `
    -Department Бухгалтерия -Position 'Гл. бухгалтер'
```

Пароль показывается на экране и записывается в файл с паролями.

### Диалог

```powershell
.\New-ServerUsers.ps1 -Interactive
```

Скрипт спрашивает имя, фамилию, телефон, отдел и предлагает свободный логин
(занят - добавит 2, 3, ...). Enter принимает предложенный логин. Пустое имя - конец.

### Список

```powershell
.\New-ServerUsers.ps1 -UserList D:\users.csv -WhatIf   # проверка
.\New-ServerUsers.ps1 -UserList D:\users.csv
```

Без `-UserList` берётся `New-ServerUsers.users.csv` рядом со скриптом. Список проверяется
целиком до начала: при ошибках скрипт перечисляет их все и никого не создаёт.

### Серия

Начало логина и количество - например, для учебного класса или временных сотрудников:

```powershell
.\New-ServerUsers.ps1 -LoginPrefix student -Count 10 -WhatIf   # проверка
.\New-ServerUsers.ps1 -LoginPrefix student -Count 10
# student01 ... student10
```

- **Без `-StartNumber`** нумерация продолжается после самого большого существующего номера:
  если `student01`-`student03` уже есть, `-Count 5` создаст `student04`-`student08`,
  то есть ровно 5 новых.
- **С `-StartNumber`** - ровно этот диапазон; уже существующие учётные записи из него
  пропускаются: `-StartNumber 1 -Count 10` всегда означает `student01`-`student10`.
- Номер дополняется нулями до длины последнего номера, но не меньше двух цифр:
  `01`-`10`, `001`-`120`. Своя длина - `-NumberWidth 3`.
- `-Department`, `-Position`, `-Description` дают одно описание всем, `-Password` - один
  пароль всем (иначе у каждого свой случайный), `-ExtraGroups` и `-AccountExpires` тоже
  действуют на всю серию.

Из меню (запуск без параметров, пункт 3) скрипт спросит начало логина, количество,
начальный номер и описание, покажет диапазон и попросит подтверждение.

## Список пользователей (CSV)

Разделитель - точка с запятой (запятая тоже подойдёт). Кодировка - UTF-8 или ANSI,
то есть файл можно сохранять и из Блокнота, и из Excel. Первая строка - названия столбцов.
Все столбцы необязательны, но в каждой строке нужен `Login` или имя.

| Столбец | Что содержит |
|---|---|
| `Login` | логин, до 20 символов; пусто - составляется из `FirstName` и `LastName` |
| `FirstName`, `LastName` | имя и фамилия |
| `FullName` | ФИО; пусто - «Имя Фамилия», а без них учётная запись создаётся без ФИО |
| `Password` | пароль; пусто - будет сгенерирован (12 букв и цифр без похожих символов) |
| `Description` | описание учётной записи; пусто - составляется из `Department` и `Position` |
| `Department`, `Position` | отдел и должность; вместе не длиннее 48 символов |
| `Phone` | телефон; попадает только в файл с паролями, в учётную запись - нет |
| `Groups` | дополнительные группы через `\|`, например `1C_Users\|Принтеры` |

Пример (`New-ServerUsers.users.example.csv`):

```
Login;FirstName;LastName;FullName;Department;Position;Phone;Password;Groups
;Іван;Петренко;;Бухгалтерия;Гл. бухгалтер;000 000 00 01;;
o.kovalenko;;;Коваленко Ольга Петровна;Отдел продаж;Менеджер;000 000 00 02;;
ivanov;;;;;;;;
```

Первая строка создаст `i.petrenko`, вторая - `o.kovalenko`, третья - `ivanov` без ФИО.

### Перенос на другой сервер

В качестве списка подходит файл с паролями, который скрипт создал на старом сервере
(`Login;FullName;Phone;Password`): пользователи создадутся с теми же паролями.
Подробнее о переезде - в [UserProfileMove](../UserProfileMove/README.md).

## Параметры

| Параметр | Что делает | По умолчанию |
|---|---|---|
| `-Login` (первый параметр) | логин одного пользователя | - |
| `-FirstName`, `-LastName` | имя и фамилия; без `-Login` логин составляется из них | - |
| `-FullName` | ФИО вместо «Имя Фамилия» | - |
| `-Phone`, `-Department`, `-Position`, `-Description` | телефон, отдел, должность, описание | - |
| `-Password` | готовый пароль вместо сгенерированного (в серии - один на всех) | генерируется |
| `-Interactive` | диалог, по одному | - |
| `-UserList` | список CSV | `New-ServerUsers.users.csv` |
| `-LoginPrefix`, `-Count` | серия: начало логина и сколько создать (1-999) | - |
| `-StartNumber` | серия: первый номер | после самого большого существующего |
| `-NumberWidth` | серия: цифр в номере | по последнему номеру, минимум 2 |
| `-ExtraGroups` | дополнительные группы для всех, по имени или SID | - |
| `-AccountExpires` | дата окончания действия учётной записи (временный сотрудник) | не истекает |
| `-PasswordNeverExpires:$false` | срок пароля по политике сервера (обычно 42 дня) | срок не ограничен |
| `-PasswordLength` | длина пароля, 8-64 | `12` |
| `-PasswordFile` | куда записать логины и пароли; существующий файл дописывается | новый файл |
| `-LoginTemplate` | шаблон логина: `{f}` - первая буква имени, `{first}` - имя, `{last}` - фамилия | `{f}.{last}` |
| `-WhatIf` | показать, что будет сделано, ничего не меняя | - |

Примеры:

```powershell
# временный сотрудник с доступом к группе 1С
.\New-ServerUsers.ps1 temp1 -AccountExpires 2026-12-31 -ExtraGroups 1C_Users

# логин вида petrenko.ivan
.\New-ServerUsers.ps1 -FirstName Іван -LastName Петренко -LoginTemplate '{last}.{first}'

# дописывать пароли в один постоянный файл
.\New-ServerUsers.ps1 -Interactive -PasswordFile D:\Admin\passwords.csv
```

## Что делает скрипт

- Логин из имени и фамилии - украинская транслитерация (КМУ 2010), русские буквы тоже
  обрабатываются: Іван Петренко -> `i.petrenko`, Юлія Згуровська -> `y.zghurovska`, Сидоров -> `sydorov`
  (буква «и» по украинским правилам - `y`).
- Создаёт локальную учётную запись и добавляет её в группы «Пользователи»
  и «Пользователи удалённого рабочего стола» (по SID - работает и в русской,
  и в украинской Windows), а также в группы из `-ExtraGroups` и столбца `Groups`.
  Группы добавляются через `net localgroup`: так работает и на серверах, где
  `Add-LocalGroupMember` не видит групп из-за сбоя SAM.
- Уже существующие учётные записи не трогает и пароли им не меняет - список можно
  запускать повторно.
- Логины и пароли созданных записывает в `New-ServerUsers.passwords_<дата_время>.csv`
  рядом со списком (в диалоге и для одного пользователя - рядом со скриптом).
  Доступ к этому файлу только у администраторов; **после раздачи паролей удалите его**.

Новым учётным записям ставится «Срок действия пароля не ограничен»: с истёкшим паролем
по RDP чаще всего не войти. Уже созданным пользователям эту настройку ставит
`Set-PasswordNeverExpires.ps1`: он обрабатывает все локальные учётные записи, кроме встроенных.
