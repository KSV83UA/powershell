# RDP Visual Effects

Скрипт отключает визуальные эффекты окон для всех пользователей сервера, чтобы в RDP-сессиях окна не «дёргались» при перетаскивании и изменении размера.

## Зачем это нужно

Когда включена опция «Отображать содержимое окна при перетаскивании», RDP перерисовывает всё окно на каждом шаге движения мыши. По сети это выглядит как рывки. Если опцию выключить, при перетаскивании и изменении размера рисуется только рамка, а содержимое обновляется один раз в конце.

## Состав проекта

| Файл | Назначение |
|------|------------|
| `Set-RdpVisualEffects.ps1` | Отключение эффектов и откат к настройкам по умолчанию |

## Требования

- Windows Server или Windows 10/11
- PowerShell 5.1+
- Права **администратора**

> **Кодировка:** `.ps1` должен быть в **UTF-8 с BOM**.  
> PowerShell 5.1 без BOM неправильно читает кириллицу и выдаёт ошибку `Unexpected token`.

## Быстрый старт

Папку со скриптом можно разместить на любом диске. Откройте PowerShell **от имени администратора** и перейдите в неё.

### 1. Пробный прогон

Ничего не меняет, только показывает, какие профили будут затронуты:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\Set-RdpVisualEffects.ps1 -WhatIf
```

### 2. Применение

```powershell
.\Set-RdpVisualEffects.ps1
```

### 3. Повторный вход

Изменения действуют только после повторного входа пользователя. Тем, кто сейчас в системе, нужно выйти и войти заново (не просто отключить RDP-сессию).

## Что меняет скрипт

| Где | Параметр | Значение | Действие |
|-----|----------|----------|----------|
| Профиль пользователя: `Control Panel\Desktop` | `DragFullWindows` | `0` | При перетаскивании и изменении размера рисуется только рамка окна |
| Профиль пользователя: `Control Panel\Desktop\WindowMetrics` | `MinAnimate` | `0` | Нет анимации сворачивания и разворачивания окон |
| Компьютер: `HKLM\SOFTWARE\Policies\Microsoft\Windows\DWM` | `DisallowAnimations` | `1` | Политика «Не разрешать анимацию окон» для всех |

Пользовательские параметры записываются:

- во все существующие профили пользователей (локальные, доменные, Azure AD);
- в профиль `Default` — его настройки получают новые пользователи при первом входе.

Системные и служебные учётные записи (SYSTEM, LOCAL SERVICE, учётные записи служб) не затрагиваются.

Если пользователь сейчас в системе, скрипт правит его загруженный куст реестра. Если нет — временно загружает `NTUSER.DAT` из папки профиля, вносит изменения и выгружает.

## Параметры

| Параметр | Описание |
|----------|----------|
| `-WhatIf` | Показать, что будет изменено, ничего не меняя |
| `-Restore` | Вернуть настройки Windows по умолчанию |
| `-SkipDefaultProfile` | Не изменять профиль `Default` |

## Откат

```powershell
.\Set-RdpVisualEffects.ps1 -Restore
```

Скрипт вернёт значения Windows по умолчанию (`DragFullWindows = 1`, `MinAnimate = 1`) во всех профилях и удалит политику DWM.

> Прежние значения скрипт не запоминает. Если кто-то из пользователей отключил эффекты сам ещё до запуска скрипта, после отката они у него будут включены.

## Проверка

```powershell
# Параметры текущего пользователя
Get-ItemProperty 'HKCU:\Control Panel\Desktop' -Name DragFullWindows
Get-ItemProperty 'HKCU:\Control Panel\Desktop\WindowMetrics' -Name MinAnimate

# Политика компьютера
Get-ItemProperty 'HKLM:\SOFTWARE\Policies\Microsoft\Windows\DWM' -Name DisallowAnimations
```

## Альтернатива на стороне клиента

Тот же эффект можно получить без изменений на сервере — в настройках подключения. В `mstsc` на вкладке **Взаимодействие** снимите:

- «Отображать содержимое окна при перетаскивании»
- «Визуальные эффекты при отображении меню и окон»

В `.rdp`-файле это строки:

```
disable full window drag:i:1
disable menu anims:i:1
```

Настройка действует только для того, кто подключается с этим файлом.

## Важные замечания

1. **Запуск только от администратора** — без этого скрипт не сможет изменить чужие профили и политику.
2. **Повторный запуск безопасен** — значения просто записываются заново.
3. **Новые пользователи** получают настройки из профиля `Default`. Профили, созданные до запуска скрипта, обновляются при запуске; повторно запускать скрипт для новых пользователей не нужно.
4. **Групповые политики домена** могут переопределить эти параметры при следующем обновлении политик.
5. **Плавность зависит и от транспорта RDP** — по UDP картинка обычно идёт ровнее, чем по TCP. Убедитесь, что UDP-порт RDP открыт в firewall (см. `RDP_GEO_IP_RDP`).

## Устранение неполадок

| Проблема | Решение |
|----------|---------|
| `Access is denied` / скрипт не запускается | Запустите PowerShell от администратора |
| `ExecutionPolicy` блокирует скрипт | `Set-ExecutionPolicy -Scope Process Bypass` |
| «Файл … не имеет цифровой подписи» | Файл скачан из интернета: `Unblock-File .\*.ps1` или `Set-ExecutionPolicy -Scope Process Bypass` |
| `Unexpected token` / кракозябры в ошибке | Файл сохранён без BOM — пересохраните в UTF-8 с BOM |
| `Профиль пропущен: … файл не найден` | Папка профиля удалена, а запись в реестре осталась — такой профиль можно не учитывать |
| `Профиль пропущен: … reg.exe load` | `NTUSER.DAT` занят другим процессом — запустите скрипт ещё раз позже |
| Окна по-прежнему дёргаются | Пользователь не перезашёл; проверьте значения командами из раздела «Проверка» |
| Скрипт завершился с кодом 1 | Часть профилей пропущена — причины указаны в предупреждениях выше по выводу |
