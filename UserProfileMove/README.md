# Перенос пользователей RDP-сервера

Скрипты PowerShell для переезда пользователей со старого RDP-сервера на новый:
забрать данные каждого пользователя в архив, создать учётные записи на новом сервере
и разложить данные по их профилям.

Все скрипты запускаются в Windows PowerShell 5.1 **от имени администратора**.
Держите все файлы в одной папке: скрипты ищут настройки рядом с собой.
У каждого скрипта есть ключ `-WhatIf` - проверка без изменений; начинайте с него.

## Файлы

| Файл | Где запускать | Что делает |
|---|---|---|
| `Backup-UserProfiles.ps1` | старый сервер | архивирует данные каждого пользователя в отдельный zip |
| `Copy-1CBaseList.ps1` | старый сервер | отдельно копирует список баз 1С (`ibases.v8i`) каждого пользователя |
| `Backup-UserProfiles.config.psd1` | оба | настройки: откуда, куда, кого и что исключать |
| `New-ServerUsers.ps1` | новый сервер | создаёт учётные записи по списку |
| `New-ServerUsers.users.csv` | новый сервер | шаблон списка пользователей |
| `Restore-UserProfiles.ps1` | новый сервер | создаёт профили и распаковывает в них архивы |

## Порядок переноса

### 1. Старый сервер: бэкап

1. Заполните `Backup-UserProfiles.config.psd1` - как минимум `BackupRoot` (куда складывать).
2. Проверьте настройки и список профилей:
   ```powershell
   .\Backup-UserProfiles.ps1 -WhatIf
   ```
3. Запустите бэкап:
   ```powershell
   .\Backup-UserProfiles.ps1
   ```

Результат - папка на каждого пользователя с одним архивом:

```
D:\ProfileBackup\
  i.petrenko\
    i.petrenko_2026-10-24_125228.zip
    i.petrenko_2026-10-24_125228.log   <- только если какие-то файлы пропущены
```

Пока архив пишется, он называется `*.zip.partial`. Если такой файл остался - бэкап этого
пользователя прервался, запустите заново.

`Copy-1CBaseList.ps1` нужен, только если список баз 1С нужен отдельным файлом:
он кладёт `ibases.v8i` в те же папки пользователей. В архив этот файл и так попадает
через настройку `Include`.

### 2. Новый сервер: учётные записи

1. Скопируйте на новый сервер папку со скриптами и папку бэкапа целиком.
2. Подготовьте список пользователей (см. «Список пользователей» ниже). Подходит файл
   с паролями, который `New-ServerUsers.ps1` создал на старом сервере.
3. Проверьте список:
   ```powershell
   .\New-ServerUsers.ps1 -UserList D:\users.csv -WhatIf
   ```
4. Создайте пользователей:
   ```powershell
   .\New-ServerUsers.ps1 -UserList D:\users.csv -PasswordNeverExpires
   ```

### 3. Новый сервер: данные в профили

Делайте это **до первого входа пользователей**.

1. Посмотрите, кто и из какого архива будет восстановлен:
   ```powershell
   .\Restore-UserProfiles.ps1 -BackupRoot D:\ProfileBackup -WhatIf
   ```
2. Восстановите одного пользователя, зайдите под ним по RDP и проверьте
   Рабочий стол, Документы и 1С:
   ```powershell
   .\Restore-UserProfiles.ps1 -BackupRoot D:\ProfileBackup -User i.petrenko
   ```
3. Восстановите остальных:
   ```powershell
   .\Restore-UserProfiles.ps1 -BackupRoot D:\ProfileBackup
   ```

## Настройки: Backup-UserProfiles.config.psd1

Пути пишутся в одинарных кавычках как есть, обратную косую черту удваивать не нужно.
Перед работой файл проверяется; при ошибках скрипт перечисляет их все и ничего не делает.
Параметры командной строки с теми же именами имеют приоритет над файлом.

| Настройка | Что задаёт |
|---|---|
| `ProfilesRoot` | откуда копировать: папка с профилями, `'C:\Users'` или `'\\RDS01\C$\Users'` |
| `BackupRoot` | куда складывать бэкап; из этой же папки `Restore-UserProfiles.ps1` берёт архивы |
| `ExcludeUser` | профили, которые не копировать; можно с `*` и `?` |
| `User` | обработать только эти профили (по умолчанию - все) |
| `Exclude` | что не класть в архив: путь от корня профиля, можно с масками |
| `Include` | что взять в архив вопреки `Exclude`: точный путь от корня профиля, без масок |
| `CompressionLevel` | `Optimal` - меньше размер, `Fastest` - быстрее, `NoCompression` - без сжатия |

Примеры для `Exclude`:

| Запись | Что пропускает |
|---|---|
| `'AppData'` | папку в корне профиля |
| `'Documents\Outlook Files'` | одну вложенную папку |
| `'Downloads\*.iso'` | файлы по маске в папке и её подпапках |
| `'*\Cache'` | папку `Cache` на любой глубине, кроме корня |
| `'*.tmp'` | файлы по маске где угодно |

Пример для `Include`: `'AppData\Roaming\1C\1CEStart\ibases.v8i'` - список баз 1С.
Можно указать и папку целиком. У кого такого файла нет, для того запись не срабатывает.

Какие настройки читает каждый скрипт:

- `Backup-UserProfiles.ps1` - все;
- `Copy-1CBaseList.ps1` - `ProfilesRoot`, `BackupRoot`, `User`, `ExcludeUser`;
- `Restore-UserProfiles.ps1` - только `BackupRoot`.

## Что попадает в архив

Всё содержимое профиля: Рабочий стол, Документы, Загрузки, Изображения и любые папки
и файлы пользователя. Не попадают:

- `AppData` и остальное из `Exclude`, кроме того, что указано в `Include`;
- скрытые и системные файлы в корне профиля (`NTUSER.DAT` и т.п.);
- `desktop.ini`, `Thumbs.db` и другие системные файлы внутри папок;
- ссылки-junction вроде «Моя музыка» внутри Документов;
- файлы OneDrive, которые лежат только в облаке.

Файлы, занятые другой программой (например, открытая база Outlook), пропускаются
и перечисляются в логе рядом с архивом. Надёжнее делать бэкап, когда пользователи вышли.

## Список пользователей: New-ServerUsers.users.csv

Разделитель - точка с запятой (запятая тоже подойдёт). Кодировка - UTF-8 или ANSI,
то есть файл можно сохранять и из Блокнота, и из Excel. Первая строка - названия столбцов.

| Столбец | Что содержит |
|---|---|
| `Login` | логин, обязательно; до 20 символов |
| `FullName` | ФИО, обязательно |
| `Password` | пароль; если пусто - будет сгенерирован (12 букв и цифр без похожих символов) |
| `Description` | описание учётной записи; если пусто - составляется из `Department` и `Position` |
| `Department`, `Position` | отдел и должность |
| `Phone` | телефон; попадает только в файл с паролями, в учётную запись - нет |

Пример:

```
Login;FullName;Password;Department;Position;Phone
i.petrenko;Петренко Иван Иванович;;Директор;;000 000 00 01
o.kovalenko;Коваленко Ольга Петровна;;Бухгалтерия;Гл. бухгалтер;000 000 00 02
```

Что делает `New-ServerUsers.ps1`:

- создаёт локальную учётную запись и добавляет её в группы «Пользователи»
  и «Пользователи удалённого рабочего стола»;
- уже существующие учётные записи не трогает и пароли им не меняет;
- логины и пароли созданных записывает в `New-ServerUsers.passwords_<дата_время>.csv`
  рядом со списком. Доступ к этому файлу только у администраторов;
  **после раздачи паролей удалите его**.

Без ключа `-PasswordNeverExpires` пароли истекают по политике сервера (обычно через 42 дня),
а с истёкшим паролем по RDP чаще всего не войти.

## Восстановление: Restore-UserProfiles.ps1

- Имя папки в `BackupRoot` должно совпадать с логином на новом сервере.
  Берётся самый свежий архив из папки.
- Если профиля у пользователя ещё нет, он создаётся - входить под пользователем не нужно.
- Файлы, которые в профиле уже есть, не перезаписываются: повторный запуск ничего не затрёт.
  Пропущенные файлы перечисляются в `<логин>_restore_<дата_время>.log` рядом с архивом.
- Профиль пользователя, который сейчас в системе, пропускается.
- Если рядом с архивом лежит `ibases.v8i` (от `Copy-1CBaseList.ps1`), а в профиле своего нет,
  он кладётся в `AppData\Roaming\1C\1CEStart`.

Ограничения:

- переносится только то, что было в архиве; настройки программ из `AppData`
  (браузеры, почта и прочее, кроме указанного в `Include`) остаются на старом сервере;
- если на новом сервере включены диски профилей (UPD или FSLogix), этот способ не подходит:
  данные окажутся в локальном профиле, которым система не пользуется.

## Если что-то не так

**Скрипт не запускается из-за политики выполнения** - запустите так:

```powershell
powershell -ExecutionPolicy Bypass -File .\Backup-UserProfiles.ps1 -WhatIf
```

**Ошибки разбора или «кракозябры» в сообщениях.** Файлы сохранены в UTF-8 с BOM.
Переносите их на сервер файлами, а не вставкой текста в новый файл.

**Окно замерло, пока не нажали Enter.** Щелчок мышью в окне консоли ставит вывод на паузу.
`Backup-UserProfiles.ps1` и `Restore-UserProfiles.ps1` на время работы это отключают;
если окно всё же замерло, нажмите Esc или Enter - работа продолжится с того же места.

**Скрипт сообщает об ошибках в настройках или списке** - он перечисляет все сразу;
исправьте их и запустите снова. Пока ошибки есть, скрипт ничего не меняет.
